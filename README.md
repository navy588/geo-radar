# 글로벌 지정학 레이더

한국 관점의 가중치(동아시아·한반도 35%, 중동 30%, 유럽·러시아 20%, 미국 15%)로 지역별 지정학 동향을 한눈에 보여 주는 대시보드입니다.

**주소:** https://navy588.github.io/geo-radar/

- 매주 월요일 06:47(한국시간)에 최신 동향을 조사해 `data/geo.json`에 주간 기록을 쌓습니다.
- 지난 1주, 지난 한 달, 마지막 방문 이후 무엇이 바뀌었는지 비교해 볼 수 있습니다.
- 위험 지수는 공개 보도를 바탕으로 매긴 편집 판단 점수이며 공식 통계가 아닙니다. 출처는 페이지 하단에 있습니다.

## 구조

- `index.html`: 화면 (폰트 내장, 외부 접속 없이 동작)
- `data/geo.json`: 주간 스냅샷, 사건, 일정, 전문가 견해, 출처
- `data/world-110m.json`: 세계 지도 (world-atlas)
- `vendor/`: d3, topojson-client
