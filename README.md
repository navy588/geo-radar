# 글로벌 지정학 레이더

한국 관점의 가중치(동아시아·한반도 35%, 중동 30%, 유럽·러시아 20%, 미국 15%)로 지역별 지정학 동향을 한눈에 보여 주는 대시보드입니다.

**주소:** https://navy588.github.io/geo-radar/

- 매주 월요일 06:47(한국시간)에 최신 동향을 조사해 `data/geo.json`에 주간 기록을 쌓습니다.
- 핵심 판단마다 가능성 척도, 확신도, 근거 출처(발행처·발행일·신뢰 등급 A–D·원문 링크)와 반대 근거를 표시합니다.
- 위험 지수는 5개 구성요소(무력충돌, 확전, 외교 경색, 경제·에너지, 한국 노출)의 가중합으로 구성 내역을 공개합니다. 공식 통계가 아닌 편집 판단 점수입니다.
- 싱크탱크·IB·공식기관 리포트, 시나리오와 선행 지표, 출처 감사와 방법론을 함께 제공합니다.

## 구조

- `index.html`: 화면 (폰트 내장, 외부 접속 없이 동작)
- `data/geo.json` (v2): 주간 스냅샷, 핵심 판단, 시나리오, 사건, 일정, 전문가 견해, 등급이 매겨진 출처, 방법론
- `data/world-110m.json`: 세계 지도 (world-atlas)
- `vendor/`: d3, topojson-client
